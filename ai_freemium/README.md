# ذكا · DumbAI — نموذج Freemium للـ AI

نموذج أوّلي (prototype) لتطبيق ذكاء اصطناعي بنموذج ربح **Freemium**، الفكرة الأساسية فيه:
**النسخة المجانية غبية بقصد** — وكل ما تدفع أكتر يبقى أذكى.

افتح `index.html` في أي متصفح مباشرةً — كل المنطق شغّال في المتصفح، بدون سيرفر ولا API keys.

---

## 💡 الفكرة

| الطبقة | السعر | بترجع إيه؟ |
|--------|-------|------------|
| 🥔 **مجاني (Potato)** | مجاناً + **إعلان لكل شات** | إجابات **غلط بثقة** — تسأله `1+1` يقول `11` |
| 🧠 **ذكي (Smart)** | `$0.10` / سؤال | إجابات صح ومختصرة، بدون إعلانات |
| 💎 **عبقري (Genius)** | `$0.30` / سؤال | إجابة صح **+ شرح وخطوات** للمادة أو أي موضوع |
| 📚 **حزم المجالات** | `$2–$3` / مرة واحدة | افتح مجال (رياضة/علوم/برمجة/لغات) = ذكاء **مجاني للأبد** في المجال ده |
| 🎬 **استوديو الفيديو** | `$10` / شهر | فيديو لحد **5 دقائق**، رصيد يومي **يترفرش كل يوم** |

### ميكانيكا اللعبة (Game mechanics)
- **محفظة + ماس (💎):** المستخدم يشحن رصيد، وكل سؤال ذكي بيتخصم منه.
- **الإعلان:** يظهر مرة واحدة قبل كل شات جديد في النسخة المجانية، مع زر «شيل الإعلانات» (upsell).
- **الـUpsell اللحظي:** بعد أي إجابة غبية بيظهر زر «هات الإجابة الصح بـ $0.10» — أقوى نقطة تحويل.
- **حزم المجالات:** بتبيع «عمودي» كامل — الطالب يفتح حزمة الرياضيات مرة، وبعدها كل أسئلة
  الرياضيات بترد عليه بمستوى مدرّس مجاناً (حتى في النسخة المجانية وبدون إعلان).
- **رصيد الفيديو اليومي:** 300 ثانية تترفرش كل يوم — يخلّي الاشتراك «متجدد» ويشجّع الاستخدام اليومي.
- **لوحة الأرباح:** بتوضّح فكرة الربح بالأرقام (إجمالي الدخل، أسئلة مدفوعة، دخل الإعلانات، سجل المعاملات).

## 🧪 جرّبها

افتح `index.html` وجرّب:
1. اكتب `1+1` في النسخة المجانية → هيرد `11`. اضغط «هات الإجابة الصح» → `2`.
2. اسأل «عاصمة مصر» مجاناً → إجابة غلط. رقّي لـ Smart → «القاهرة».
3. جرّب «عبقري» → نفس السؤال بس مع شرح وخطوات.
4. **افتح حزمة «الرياضيات»** وبعدها اسأل `1+1` في النسخة المجانية → هتلاقيها بقت `2` وبشرح!
5. اشترك في استوديو الفيديو ($10) → ولّد فيديو، وشوف الرصيد اليومي بيقل، واعمل ريفريش.
6. شوف **لوحة الأرباح** تحت بتتحدّث مع كل عملية.

> الحالة بتتحفظ في المتصفح (localStorage)، فمتقلقش لو عملت refresh. زر «↺ تصفير» بيرجّع كله من الأول.

## 💰 ملاحظات على الاقتصاديات (مهمة قبل الإطلاق الحقيقي)

هي دي النقاط اللي بتفرّق بين فكرة حلوة ومشروع بيكسب فعلاً:

1. **تكلفة الـAI الحقيقية:** كل رد من موديل قوي بيكلّف فلوس (tokens). لازم سعر السؤال (`$0.10`) يكون **أعلى من التكلفة + هامش**.
2. **الفيديو غالي جداً:** توليد دقايق فيديو بالـAI من أغلى العمليات. `$10/شهر` مقابل 5 دقايق يومياً = **150 دقيقة/شهر** ممكن يخسّرك لو التكلفة الحقيقية أعلى. احسبها كويس أو قلّل الحد اليومي.
3. **«النسخة الغبية» سلاح ذو حدين:** مضحكة وبتلفت النظر، بس ممكن تخلّي ناس تسيب التطبيق وتفتكره فعلاً وحش. الحل: تخليها **واضحة إنها نكتة/تيزر** (زي ما هي هنا، عليها لابل «غالباً غلط») + الترقية سهلة وفورية.
4. **الإعلانات:** دخل بسيط لكنه بيغطّي تكلفة المستخدم المجاني جزئياً ويضغط عليه يرقّي.

## 🧠 الـAI ده بتاع الموقع نفسه

«الذكاء» هنا **محرك خاص بالموقع** (مش كلود ولا أي API خارجي) عايش في `engine.js`
باسم `ZakaAI`. نفس الملف بيشتغل في المتصفح **و** في السيرفر — مرجع واحد للعقل.
لما نكبّر الموديل بعدين، بنوسّع `engine.js` بس والواجهة ما تتغيّرش.

## 🏗️ المعمارية — مصدر واحد للحقيقة

| الطبقة | الملف | المسؤولية |
|--------|-------|-----------|
| العقل | `engine.js` (`ZakaAI`) | الردود + اكتشاف المجال — متصفح وسيرفر |
| المحفظة | `wallet.js` (`ZakaWallet`) | الرصيد، الخصم، الحزم، الاشتراك، السجل، الإحصائيات |
| الواجهة | `index.html` | غلاف رفيع فوق المحرك والمحفظة (نفس قواعد السيرفر) |
| السيرفر | `server/server.js` | يقدّم الواجهة + API يستخدم نفس `wallet.js` |

الواجهة والسيرفر **بيستخدموا نفس `wallet.js`**، فقواعد الخصم ما تختلفش بين العميل والسيرفر.

## 🖥️ السيرفر — جاهز ومستني (مش شغّال دلوقتي)

الواجهة شغّالة لوحدها في المتصفح من غير سيرفر. كود السيرفر **متجهّز ومستني** لحد
ما يتوفر سيرفر نرفعه عليه — Node صافي، **بدون أي مكتبات خارجية**:

```bash
node server/server.js     # بعدها افتح http://localhost:3000
```

بيقدّم الواجهة + API (الخصم والتحقق من الرصيد بيحصلوا في السيرفر — آمن):
- `POST /api/ask` بـ `{ "question": "1+1", "tier": "free|smart|genius" }` → رد + الرصيد الجديد.
- `POST /api/topup` بـ `{ "dollars": 5, "diamonds": 60 }` → شحن.
- `POST /api/unlock-domain` بـ `{ "id": "math" }` → فتح حزمة مجال.
- `POST /api/subscribe-video` → اشتراك الفيديو.
- `POST /api/ad` → تسجيل ظهور إعلان.
- `GET /api/account` → بيانات الحساب. · `GET /api/health` → فحص.

الحسابات منفصلة لكل جلسة عن طريق هيدر `x-session`.

## ✅ الاختبارات

اختبارات بدون مكتبات (Node المدمج):

```bash
node --test                # من فولدر ai_freemium (بيكتشف test/ تلقائياً)
# أو:  cd server && npm test
```

24 اختبار بيغطّي: المحرك (الردود الغبية/الذكية، المجالات، تأمين HTML)، المحفظة (الخصم،
نقص الرصيد، الحزم، الاشتراك)، والواجهة (تكامل DOM للسيناريوهات الأساسية).

## 🗂️ الملفات
- `index.html` — الواجهة الكاملة (شغّالة standalone في المتصفح).
- `engine.js` — **عقل الموقع** (`ZakaAI`)؛ يشتغل في المتصفح والسيرفر.
- `wallet.js` — منطق المحفظة والربح (`ZakaWallet`)؛ مشترك بين الواجهة والسيرفر.
- `server/server.js` — سيرفر Node جاهز بدون مكتبات (مستني سيرفر).
- `server/package.json` — `npm start` / `npm test`.
- `test/` — اختبارات المحرك والمحفظة والواجهة.
- `README.md` — الملف ده.

> لتوضيح الفرق بين الطبقات — بيتوسّع لموديل أقوى مع الوقت.
